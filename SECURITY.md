# Security policy

Job Orchestrator is an experimental project maintained by one person. Thank you for helping keep the people who use it safe.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub: open the Security tab of this repository and click "Report a vulnerability".

Include what you found, the steps to reproduce it and the version you tested. You will get a reply as soon as possible.

## Supported versions

Only the latest release receives security fixes.
